# iiith-aiml

A Jupyter notebook covering Python basics and introductory data science libraries, created for an IIIT Hyderabad AI/ML course.

## What it covers

The notebook walks through:

- **Strings** — creation, indexing, special characters
- **Lists** — ordered collections, `extend`, mixed data types
- **NumPy** — array operations (implied by the library list)
- **Matplotlib** — plotting (implied by the library list)
- **NLTK** — basic natural language processing (implied by the library list)

## Built with

- Python 3
- Jupyter Notebook
- NumPy, Matplotlib, NLTK

## How to run

**In Google Colab** (easiest): click the "Open in Colab" badge at the top of the notebook.

**Locally:**
```bash
pip install jupyter numpy matplotlib nltk
jupyter notebook AIML_Sep_2026_Basics_of_Python.ipynb
```
